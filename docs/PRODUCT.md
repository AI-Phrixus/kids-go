# 產品願景

## 一句話

讓 10–11 歲孩子在暑假跟著《西遊記》師徒，快樂學會圍棋裡的戰略思維，並養成護眼休息習慣；家長用日／繁中／英陪學。

## 不是什麼

- 不是職業圍棋客戶端  
- 不是強 AI 虐菜器  
- 不是依賴 Cloudflare 付費 AI 的產品  

## 對標與差異（騰訊少兒圍棋等）

| 維度 | 常見少兒圍棋 | Kids Igo |
|------|--------------|---------|
| AI | 強引擎復盤 | 弱引擎保 mastery + 可插拔暖教練 |
| 敘事 | 動畫課 | **西遊取經路** |
| 課後 | 習題 | **每課必人機** |
| 語言 | 偏單語 | 日／繁中／英 |
| 健康 | 少見 | **角色護眼儀式** |
| 部署 | App | CF Free Web |

## 核心體驗循環

註冊（暱稱）→ 選語言 → 取經地圖 → 課（Hook→動手→標籤→測→人機）→ 徽章 → 休息站 → 續  

## 帳號

- 家長 email+password + 多孩子檔  
- 快速暱稱+PIN  
- 進度綁 `child_id`  

## 成功體感

- 孩子被角色叫出名、想再玩一課  
- 休息時願意遠眺（相信師徒）  
- 家長能看懂「今天練了預見／連結」
