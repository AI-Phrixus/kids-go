# 國際化（ja / zh-Hant / en）

## 語系

| code | 說明 |
|------|------|
| `ja` | 日本語（學校語境預設可） |
| `zh-Hant` | **繁體**漢字（非簡體） |
| `en` | English |

UI locale = 角色語言 = 靜態句庫目錄。

## 名字插槽

所有角色臺詞：

```text
{{name}}  →  child.nickname
```

實作：`t('key', { name })`。  
LLM：請求帶 `childName` + `locale`。
