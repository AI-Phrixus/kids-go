# 角色關懷與幻想倫理

---

## 1. 為何重要

孩子會認同角色說的話——像相信聖誕老人從煙囪送禮物。  
這份天真與好奇心是人類珍貴能力；本產品**借用且守護**它來：

1. 教圍棋戰略  
2. 在「聽話窗口」（休息時）植入護眼習慣  

---

## 2. 角色與職責（《西遊記》）

| speaker | 角色 | 職責 |
|---------|------|------|
| wukong | 孫悟空 | 主教練：提示、機智、試錯鼓勵 |
| tangseng | 唐僧 | 規則、耐心、坐正／定心 |
| bajie | 豬八戒 | 休息站幽默：吃喝歇腳也光榮 |
| shaseng | 沙僧 | 連結、穩健、不拋下同伴 |
| narrator | 旁白 | 章回 Hook、過關 |

形象：原創少兒西遊風 SVG，**勿盜用**影視定裝。

---

## 3. 名字規則

- 模板一律 `{{name}}` ← `child.nickname`  
- trim；過長截斷（建議 ≤12）  
- 未建檔：日「きみ」／繁「小朋友」／英 “friend”  
- 禁止顯示 email、user id  

示例：`「{{name}}，這一手很有悟空的預見！」`

---

## 4. 語言規則

- UI locale ∈ `ja` | `zh-Hant` | `en` 為唯一真相源  
- 切換語言後，角色**下一句**即新語言，名字不變  
- zh-Hant：**繁體**，禁止簡體  
- 角色譯名見 [I18N.md](./I18N.md)

---

## 5. 幻想倫理

| 做 | 不做 |
|----|------|
| 家長摘要：「一起完成了遠眺小站」 | 「這只是假的／別傻了」 |
| 詩意可執行指令 | 偽科學療效承諾 |
| 師徒在乎孩子 | 恐嚇、羞辱 |

---

## 6. 實作鉤子

```ts
// 概念
format(t('care.far_gaze'), { name: child.nickname })
// LLM 請求必帶: { locale, childName, speaker }
```
