# 護眼與休息（一等公民）

孩子已有輕度近視風險意識：快樂玩棋 **不能** 以傷眼為代價。

---

## 1. 節奏

| 規則 | 預設 | 可調 |
|------|------|------|
| 近 20–20–20 | 每 20 分鐘活躍螢幕 → ≥20 秒遠眺類儀式 | 家長設定 |
| 單次建議 | 15–25 分鐘一段 | 是 |
| 每日柔和上限 | 約 45–60 分鐘建議 | 是；到點溫柔收工，**不扣進度、不扣星** |
| 強制休息 | 預設可關 | 家長可開「做完儀式才能續」 |

**活躍時間**：教程與對局中計入；休息 overlay、設定頁靜置可不計或減速。

---

## 2. 休息狀態機

```text
playing → care_break（凍結對局與課時計時）→ playing
```

進度不丟；回來一鍵續。

---

## 3. 儀式庫（西遊包裝 · 本地三語）

檔案：`locales/{ja,zh-Hant,en}/care-rituals.json`  
所有臺詞含 `{{name}}`，語言 = UI。

| id | 行為 | 西遊味道（方向） |
|----|------|------------------|
| far_gaze | 望向遠處 ≥20s | 與悟空望西天／遠山 |
| blink_rain | 輕眨眼 | 天庭小雨 |
| eye_orbit | 眼球慢轉一圈 | 金箍棒畫圈 |
| palm_warm | 搓熱手心覆眼 | 溫暖護佑 |
| shoulder_melt | 聳肩放鬆 | 卸包袱 |
| water_sip | 喝水（真暫停） | 甘泉 |
| sit_tall | 坐正 | 唐僧端坐 |

**禁止**：聲稱治癒近視、醫療診斷、驚嚇、系統公文彈窗。

---

## 4. UI

- 大字、高對比可開「護眼模式」  
- 避免刺眼閃爍  
- 休息畫面是**師徒關係時刻**，不是罰站倒數條  

---

## 5. 與 AI

休息文案 **離線優先**。可選 LLM 只潤色臺詞；失敗用本地庫。  
護眼路徑永不被 API 延遲拖死。
